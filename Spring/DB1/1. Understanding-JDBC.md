# JDBC 이해

## JDBC 이해!

- 애플리케이션을 개발하면 필연적으로 DB를 사용할 수 밖에 없음
- 일반적으로 DB를 사용하는 방법은
1. 커넥션 연결: TCP/IP를 사용해서 커넥션 연결(무전기 채널 맞추기?)
2. SQL 전달: 쿼리문 전달
3. 결과 응답: SQL수행 후 결과를 응답하고 어플리케이션 서버는 이 응답 활용
- 문제는 DB벤더마다 사용법이 천차만별임; 그래서 DB를 변경하면 코드를 다 수정해야 하고
각각의 DB마다 모든 사용법을 다 익혀야 함..;
- 그래서 JDBC 등장!

## JDBC 인터페이스

- JDBC(Java DataBase Connectivity)는 자바에서 DB에 접속할 수 있게 하는 API임
- 그래서 대표적으로 3가지 기능을 정의함
  - java.sql.Connection -> 연결
  - java.sql.Statement -> SQL을 담은 내용
  - java.sql.ResultSet -> SQL 요청 응답
- 그래서 개발자는 이 표준 인터페이스만 보고 만들면 됨 각각 DB벤더사가 이 표준에 맞춰서
라이브러리로 제공해줌
- 결과 -> DB 변경해도 굳이 서버 코드 수정 안해도 됨, 그리고 각각 DB사의 모든 사용법을
다 익히지 않아도 괜찮음 :) (물론 예외인 것도 있음;;)
