1. 학습 내용

- DB조회 시 ResultSet을 써야 하고 다시 자바에서 쓰기 위해서는 맞는 객체 선언 후
그 객체의 필드에 ResultSet에 있는 데이터를 get한다
- ResultSet이란 간단히 얘기해서 DB 테이블 같은 거임
- ResultSet에 있는 데이터 조회 시 (편의상 이제 rs)rs.next()를 하고 반환값에 따라서 로직을 수행하는데 <br>
cursor(데이터를 가리키는 가상의 커서)가 처음엔 아무것도 지정하고 있지 않음 그래서 next()를 실행할 때 마다 <br>
첫번 째 행부터 가리키고 비교를 시작한다 -> 그래서 if문으로 감싸서 작성한 쿼리조건으로 찾는 것이 나오면 true, <br>
안나오면 false를 반환하고 그거에 따른 로직 및 예외처리가 필요하다.

```
if (rs.next()) { 
    //cursor가 처음엔 데이터가 없는 첫 빈공간에 가있음 이걸 한 번 넘겨주는 것임
    //rs.next() -> 다음으로 넘겼을 때 boolean 값을 반환함
    Member member = new Member(); // DB응답을 받을 객체 생성
    member.setMemberId(rs.getString("member_id")); //ResultSet에 저장된 DB응답 결과 빼오기
    member.setMoney(rs.getInt("money"));
    return member;
```

쿼리는 조회를 할 시 사용하는 메서드고 반환값은 rs다!
- 데이터 수정은 쿼리문을 수정문을 작성한 후 쿼리문 파라미터에 알맞게 바인딩하면 끝-!
- 데이터 삭제는 쿼리문을 삭제문을 작성한 후 쿼리문 파라미터에 알맞게 바인당하면 끝-!
